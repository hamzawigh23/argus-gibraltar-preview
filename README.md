# Argus Gibraltar — Website Preview

An independent design concept prepared for discussion. This is not the official Argus website.

The original Argus logo and photographs are used to demonstrate the proposed experience. Product, quote and document links lead to the official Argus website; no insurance applications or personal details are collected here.

Visual structure adapted from the Margot Halloran reference on Kombai: https://kombai.com/gallery/inspirations/margot-halloran/

The preview is static HTML, CSS and JavaScript, published with GitHub Pages.
